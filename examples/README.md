# Example notes

The four files are consecutive accounting-note samples with increasing length and structural complexity. They
exercise explicit questions, labelled definitions, short fragments, lists, and long prose.

- `sample_notes_1.txt` contains introductory definitions and user categories.
- `sample_notes_2.txt` contains standards and accounting assumptions.
- `sample_notes_3.txt` contains financial-statement concepts and equations.
- `sample_notes_4.txt` contains recognition, measurement, and transaction-analysis notes.

These are realistic stress inputs, not expected-output fixtures. Automated behavior belongs in `tests/` so model
or parsing changes do not turn subjective sample output into a false correctness guarantee.
